# 鸿蒙原生感人工验收清单（Gate 4 后唯一人工环节）

## 定位与铁律

- 本清单是 **Gate 4 机器判据全部通过之后的唯一人工环节**。机器判据包括：关键功能
  intent 通过率（`RUNTIME_REQUIRED` BC 100%）、数据/状态/持久化/副作用一致性、
  无 placeholder、单一最终 HAP 构建安装成功。机器判据未全部通过前禁止启动本验收。
- native-adaptive 模式下，机器 Gate 通过后不再逐 Gate 暂停人工审批；所有「原生感」
  问题集中到本清单一次性验收。
- 机器先记录 `native_review_status = PENDING`；本验收通过后登记为 `APPROVED`，
  否则为 `REJECTED`（附整改项，整改后仅重跑本清单，不重开机器判据）。
- 验收结果复用 `android-harmony-migration-controller/scripts/_human_gate.py` 与
  `record_human_review.py` 登记，写入 `controller/human-reviews/`，禁止手工改写机器产物。
- 验收范围是「鸿蒙原生感」，不是行为等价：行为差异属于机器判据，发现行为差异必须
  回退到 P4 修复，不得在本清单里「豁免」。

## 验收前置确认

- [ ] Gate 4 机器判据全绿（`gate-report.json` verdict=PASS 且无未消化 error）
- [ ] `native_review_status` 当前为 `PENDING`
- [ ] 使用与冻结 H4ENV 一致的模拟器/设备完成全量页面走查
- [ ] 已切换到系统深色模式与默认字体缩放至少检查一次

## 一、导航与返回手势

- [ ] 页面栈使用 ArkUI `Navigation`/`NavPathStack`，转场方向与层级符合鸿蒙规范
- [ ] 侧滑/底部上滑返回手势在任何页面均可正确回退，不与页面内横向滑动手势冲突
- [ ] 返回后页面状态（滚动位置、输入内容、选中项）保持正确，无重新加载丢失
- [ ] 弹窗/浮层打开时，返回手势先关闭浮层再退出页面，顺序符合平台习惯
- [ ] 无自绘返回按钮替代系统返回语义；标题栏返回与手势行为一致

## 二、底部栏（Tabs）规范

- [ ] 底部导航使用系统 `Tabs`（BarPosition.End）实现，不自绘底栏
- [ ] Tab 数量、图标+文案布局符合鸿蒙规范（建议 ≤5 个），选中态反馈清晰
- [ ] 切换 Tab 不重建无关页面状态；各 Tab 的滚动位置独立保持
- [ ] 底栏避让安全区（导航条/手势条），内容不被遮挡
- [ ] 底栏功能入口与 Android 端能力一一对应，无缺失入口（信息/能力/入口完整性）

## 三、Dialog / Sheet 规范

- [ ] 确认类弹窗使用系统 `AlertDialog`/`CustomDialog`，危险操作有明确的主次按钮层级
- [ ] 底部面板类内容使用 `bindSheet`/半模态实现，拖拽下滑可关闭
- [ ] 弹窗宽度、圆角、遮罩、入场动画符合鸿蒙视觉规范，无 Android 风格直接搬运
- [ ] 弹窗打开时背景不可交互；关闭后焦点正确归还
- [ ] 弹窗内的业务结果（提交、删除等）与双端行为比对结果一致，无自报通过

## 四、列表与空态交互

- [ ] 长列表使用 `List` + `LazyForEach` 实现，滚动流畅、无明显掉帧或一次性全量渲染
- [ ] 空态、加载态、错误态均有鸿蒙风格的原生呈现（文案+图形+可操作按钮），非占位符
- [ ] 下拉刷新、上滑加载的交互方式符合平台习惯（如使用 `Refresh` 组件）
- [ ] 列表项的长按、滑动操作等手势与系统约定一致，且与 Android 端能力等价
- [ ] 分割线、间距、按压反馈使用系统资源，深浅色下均正常

## 五、字体与深色模式适配

- [ ] 使用系统字体与层级字号（标题/正文/辅助），随系统字体缩放不错版
- [ ] 深色模式全量页面走查：背景、卡片、文字对比度正常，无纯白残留块、无不可读文字
- [ ] 颜色使用系统资源或随深浅色切换的语义色，不硬编码单一主题色值
- [ ] 图标在深色模式下可见（无黑色图标黑底问题）
- [ ] 横竖屏/窗口尺寸变化（如适用）下布局不破版
