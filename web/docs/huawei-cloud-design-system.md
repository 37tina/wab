# 脱胎换骨 · Huawei Cloud 视觉规范

> 参考页面：[华为云码道 CodeArts 代码智能体](https://www.huaweicloud.com/intl/zh-cn/product/codearts/ai.html)，读取日期：2026-08-30。

这份规范不是对官网页面的复制，而是提取它的品牌语言，并转换成迁移验证工作台可用的产品界面规则。

## 1. 视觉原则

1. **白底、黑字、红色品牌强调**：红色只表达华为品牌、主行动和关键提醒，不把所有状态都染成红色。
2. **内容优先于装饰**：用大标题、清晰留白和分割线组织信息，避免连续堆叠圆角卡片。
3. **一屏一个主叙事**：首屏必须说明“Android → AgentTeam → HarmonyOS → 一致性证据”，复杂信息向下渐进展开。
4. **企业可信感**：状态、时间、会话、文件和测试结果都要有来源；演示数据和真实执行必须显式区分。

## 2. 颜色令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--brand` | `#C7000B` | 华为红、品牌标识、主导航当前态 |
| `--brand-deep` | `#A80712` | 红色 hover / 深色状态 |
| `--ink` | `#252B3A` | 标题、正文、主要数字 |
| `--ink-strong` | `#191919` | 主按钮和高权重标题 |
| `--text-2` | `#575D6C` | 次级说明、表格内容 |
| `--text-3` | `#8A8E99` | 辅助信息、时间、元数据 |
| `--canvas` | `#F5F5F6` | 页面画布 |
| `--surface` | `#FFFFFF` | 主内容面、表格面 |
| `--line` | `#DFE1E6` | 分割线、边框 |
| `--console-blue` | `#526ECC` | 仅用于工程链接、选中信息或 CodeArts 控制台语义 |
| `--success` | `#50B83C` | 通过、完成、连接成功 |
| `--warning` | `#E37D16` | 执行中、待审核 |

官方公共样式中同时出现 `#C7000B` / `#E41E2B` 两组华为红，以及 `#DFE1E6`、`#575D6C` 等中性颜色。本项目统一使用深红作为品牌令牌，避免红色多版本造成视觉漂移。

## 3. 字体与排版

```css
font-family: "HuaweiSans", "Frutiger", "Helvetica Neue", "Helvetica",
  "Microsoft YaHei", "PingFang SC", Arial, sans-serif;
```

- 页面标题：28–32px，字重 650–700，接近官网的强标题表现。
- 区块标题：18–20px，字重 600。
- 正文：14–16px，行高 1.6–1.75。
- 导航和按钮：14px，必要时使用 15–16px。
- 元数据：12–13px；代码、Session、时间使用等宽字体。
- 不用 10px 作为重要信息；动态日志中的小字号仅保留给时间和技术 ID。

## 4. 布局结构

### 顶部导航

- 高度 64–72px，白色背景，底部 1px 分割线。
- 左侧为品牌，中心为一级导航，右侧为连接状态和用户入口。
- 当前导航使用红色文字和 2px 底部线，不使用厚重的蓝色胶囊。

### 首页首屏

- 使用全宽白色主视觉，不放在多层圆角卡片中。
- 左侧：一句价值主张、简短说明、黑色主按钮、文字型次行动。
- 右侧：迁移证据链或平台对照图，承担“看懂产品”的视觉任务。
- 首屏下方用一条平面指标带承接任务列表。

### 工作台

- 结构为：项目标题 → 阶段轨道 → 证据带 → 主内容 + 时间线。
- 阶段轨道使用边框、状态色和进度，不为每个阶段增加独立浮影。
- 人工审核是阶段门禁，使用左侧红色标识和固定操作区突出显示。
- Android / HarmonyOS 模拟器占主内容区，日志、会话和产物放在辅助栏。

### 报告与交付

- 以结果摘要开头，再进入一致性矩阵、差异根因和完整证据。
- 文件交付使用平面列表而不是六张相同卡片；下载动作保持一个主按钮。

## 5. 形状、阴影与间距

- 基础间距采用 8px 倍数：8 / 16 / 24 / 32 / 48。
- 面板圆角默认 2px；只有主视觉和弹窗可使用 8px 以内圆角。
- 普通面板不使用浮动阴影；必要时使用 `0 1px 4px rgba(128,132,145,.12)`。
- 弹窗使用 `0 8px 32px rgba(15,23,42,.16)`，并保留明显遮罩。
- 按钮高度 36–44px，主按钮黑底白字，品牌提示和当前态使用华为红。

## 6. 本项目落地位置

- 令牌和组件覆盖：`src/styles.css` 的 `Huawei Cloud visual language` 区域。
- 首页主叙事和证据链：`src/App.tsx` 的 `HomePage`。
- 工作台真实 / 演示证据：`src/App.tsx` 的 `EvidenceRibbon`。
- 动态模拟器和时间线已经加入 `aria-live`，避免只依赖颜色传达状态。
